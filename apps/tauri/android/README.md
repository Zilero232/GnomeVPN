# Android overlay

`gen/android` is generated in full by `tauri android init` and wiped on every run of it, so
everything of ours lives here, and `scripts/setup-android-libs.mjs` lays it out over the generated
project before every android command.

Edit the files here. Edits in `gen/android` will be lost.

```text
java/                     copied into app/src/main/java/app/gnomevpn/mobile/
├── GnomeVpnService.kt    VpnService: TUN descriptor, routes, DNS, notification
└── VpnPlugin.kt          Tauri plugin: user consent, start, stop
libs/<abi>/libhysteria.so copied into app/src/main/jniLibs/<abi>/
```

The script appends the foreground permissions and the `<service>` entry with `BIND_VPN_SERVICE` to
`AndroidManifest.xml` — without it the system will not hand over the TUN descriptor.

## libhysteria.so

The same Hysteria2 client as on Windows, only built for Android. It holds the tunnel over QUIC/UDP:
Rust brings it up as a child process (`hysteria client`) with a SOCKS inbound on loopback, and
`tun2proxy` pours traffic into it from the TUN descriptor that `VpnService` handed out.

The name is not accidental. Android unpacks and allows execution only of files of the form
`lib*.so` from the native library directory — a plain `hysteria` in `assets/` cannot be run. The
path to the directory comes from `ApplicationInfo.nativeLibraryDir` rather than being assembled by
hand: it differs on an install to a work profile or to an SD card.

- **Version:** 2.10.0, builds `android-arm64`, `android-armv7`, `android-386`,
  `android-amd64`
- **Source:** <https://github.com/apernet/hysteria/releases>
- **License:** MIT

### How to update

1. Download `hysteria-android-{arm64,armv7,386,amd64}` from the releases
2. Put each one as `libhysteria.so` into the matching ABI:
   `arm64`→`arm64-v8a`, `armv7`→`armeabi-v7a`, `386`→`x86`, `amd64`→`x86_64`
3. Update the version in this file

The version must match `bin/hysteria/hysteria.exe`: the config is generated by one and the same
code from `crates/vpn-ipc`, and a mismatch will only surface at runtime.
